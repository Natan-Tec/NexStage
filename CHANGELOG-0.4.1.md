# NexStage 0.4.1

## Identidade visual

- Logo oficial fornecida pelo criador aplicada no cabeçalho do controlador.
- A mesma arte agora é o favicon do controlador, do telão e da saída para OBS.
- O antigo símbolo desenhado por CSS não é mais usado.

## Instalação no Windows

- Novo `instalar.bat` cria o atalho **NexStage** na Área de Trabalho.
- O atalho abre o `start.bat`, usa o ícone oficial e inicia minimizado.
- Não exige acesso de administrador, não altera o Registro e não instala
  dependências adicionais.
- Validação amigável caso algum arquivo obrigatório não tenha sido extraído.

## Compatibilidade

- Todos os recursos e dados da versão 0.4.0 foram preservados.
- Continua sem Node.js, Docker ou instalação de bibliotecas Python.
